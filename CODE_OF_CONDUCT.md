# Code of Conduct

This project is a friendly place to learn about automated trading.

- Be respectful and patient, especially with beginners.
- Critique code and ideas, not people.
- No harassment, insults or discrimination of any kind.
- No spam, scams, "signal selling" or get-rich-quick promotion.
- Don't ask for or share anyone's account details.

Maintainers may edit or remove content, and block people who break these rules.
To report a problem privately, contact the maintainer through their GitHub profile.
